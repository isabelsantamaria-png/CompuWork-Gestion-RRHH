# CompuWork-Gestion-RRHH
Sistema de Gesión CompuWork

Proyecto elaborado utilizando Programación Orientada a Objetos,  dónde se gestionan empleados, reportes de desempeño y departamentos.

El sistema permite administrar la información de los empleados, organizar departamentos y generar reportes de desempeño para facilitar la toma de decisiones.

En el proyecto utilizó como lenguaje de programación Java.
